# WebDevSem1Lab3
План декомпозиции:
1. Перенос структуры HTML (1 час)
2. Перенос стилей CSS (1 час)
3. Перенос файлов и структуры (1 час)
4. Изучение литературы по React (5-10 часов)
5. Замена кода из WebDevSem1Lab2 на код на React (10 - 20 часов)
Итого: 33 часа на выполнение.
Версия Node.js v22.21.0.
Версия npm 10.9.4
Запуск командой npm run dev
